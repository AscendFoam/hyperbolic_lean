## 0. 先改路径与版本

在开始前，先统一修改下面几类路径：

- traced repo 输出目录

- declaration graph 输出目录
- precise hierarchy 输出目录
- artifacts 输出目录
- `source_commit`

同时固定：

- Lean / Mathlib 版本
- LeanDojo 版本
- 运行环境

## 7. 首轮记录必须写下来的东西

- 仓库与 commit
- trace 输出规模

- closed-world graph 规模

- 是否出现 ranking 指标可读性提升

## 8. 首轮 go / no-go

### Go

继续投入新 Mathlib trace，如果：

- precise `extends` 明显增长
- `parent_prediction / ancestor_ranking` 的 ranking 指标稳定
- HGCN 至少不再像在 `lean4-example` 那样严重落后

### No-Go

先不要扩模型，如果：

- `extends` 仍旧太少
- dropped exact relations 很高
- 子图过小或过碎
- ranking 指标依然不稳定
