## 方案三：小仓库完整 trace

适合后续选择新的小型 Lean 仓库时使用。

### 1. 修改 trace 配置

编辑：

- `project_bootstrap/small_target_trace_package/configs/trace_small_repo_template.json`

至少改三项：

- `repo_url`
- `commit`
- `dst_dir`

建议保持：

- `build_deps = false`
- `num_procs = 2`

### 2. 发起 trace

```powershell
$env:PATH="C:\Users\26410\.elan\bin;$env:PATH"
$env:PYTHONPATH='project_bootstrap/leandojo_graph_scaffold/src'

& 'C:\ProgramData\anaconda3\envs\LeanDojoEnv\python.exe' `
  'project_bootstrap/leandojo_graph_scaffold/src/trace_repo_with_leandojo.py' `
  --config 'project_bootstrap/small_target_trace_package/configs/trace_small_repo_template.json'
```
